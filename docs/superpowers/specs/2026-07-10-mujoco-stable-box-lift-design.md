# MuJoCo 双臂箱子稳定抬升设计

## 目标

在 MuJoCo 中启动 Gensong 机器人，保持 `/gensong/joint_states` 以 500 Hz 发布；从 `gensong_scene.xml` 读取 `scene_box` 的准确中心和尺寸，使用双臂同步控制完成接近、抓取、夹持、抬升，并在抬升后稳定保持静止。

## 控制架构

仿真线程以 500 Hz 执行 MuJoCo 步进和状态发布。上层控制器使用有限状态机管理 `APPROACH`、`CONTACT`、`GRASP`、`LIFT`、`HOLD` 五个阶段。双臂共享箱子中心目标，保持左右对称，并对末端位置误差、速度、夹持距离和抬升高度设置权重与限幅。

底层采用带速度阻尼、力矩限幅和关节范围保护的模型预测式轨迹跟踪策略。接触和抬升阶段降低横向移动速度，提高垂直目标和速度阻尼权重；HOLD 阶段锁定箱子相对双手的目标，避免高增益振荡。

## 箱子位姿与成功判据

启动时解析 XML 中 `scene_box` 的 body `pos`、`euler` 和 geom 尺寸，得到箱子中心。控制器不得依赖硬编码箱子位置。抬升成功需同时满足：箱子中心高度高于初始高度阈值、箱子线速度低于阈值、箱子姿态变化受限，并连续保持指定时间。

## 验证

增加离线测试覆盖 XML 箱子中心解析、阶段目标生成和保持判据。在线启动 MuJoCo 后测量 `/gensong/joint_states` 频率，并从 RGB-D/渲染画面以及 MuJoCo 状态检查箱子是否离开桌面、是否持续稳定。
